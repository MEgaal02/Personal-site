Nageye School of Languages

● Live VISIT LIVE SITE →

The Problem

The client ran an English teaching company across five disconnected tools with no unified dashboard or student progress tracking:

  • Zoom for live lessons
  • WhatsApp for student communication
  • Excel for finance tracking
  • Email for file transfers
  • Third-party platform for assessments
  • No progress tracking whatsoever

Our Plan

Design and build a single unified platform that consolidates every aspect of the business into one dashboard:

  • Custom e-learning platform with course delivery
  • Built-in assessment and quiz engine
  • Self-hosted video calling (replacing Zoom)
  • Teacher feedback system with voice notes
  • Stripe subscription billing
  • Full student progress tracking & analytics

The Resolution

Delivered a production-grade, fully containerised platform deployed on AWS infrastructure:

  • Unified dashboard for teachers and students
  • All communication, lessons, payments in one place
  • Self-hosted Jitsi video server for live sessions
  • Automated billing via Stripe subscriptions
  • S3 media storage with CloudFront CDN
  • SSL-secured with automated certificate renewal

Redstone Housing CRM

● In Development

The Problem

Redstone Housing managed a growing HMO portfolio with no centralised system — critical data scattered across spreadsheets, paper contracts, and email threads:

  • Tenant records on Excel with no audit trail
  • HMO compliance deadlines managed manually
  • Maintenance requests via phone with no tracking
  • Financial reporting done manually each month
  • No room-level occupancy visibility

Our Plan

Build a purpose-built HMO CRM system that centralises every aspect of property management into a single intelligent platform:

  • Tenant management with full contract lifecycle
  • Compliance dashboard with certificate expiry alerts
  • Maintenance ticketing system with contractor assignment
  • Room-level occupancy and billing tracking
  • Automated financial reporting per property
  • Document storage with centralised access

In Progress

Currently in active development with Redstone Housing as our first HMO adopter:

  • Core tenant management module complete
  • Compliance dashboard built and in testing
  • Maintenance module in final development
  • Financial reporting module in design
  • Targeting production deployment Q3 2026

Golden Crown Security

● Live

The Problem

Golden Crown Security was managing daily operations entirely on WhatsApp, phone calls, and paper logs — no real-time oversight:

  • Guard schedules on paper and WhatsApp groups
  • Incident reports hand-written with no audit trail
  • No real-time visibility into patrol coverage
  • Client billing calculated manually each month
  • Timesheets prone to errors and disputes
  • No centralized document or certification storage

Our Plan

Design and build a unified security operations management platform with supervisor and guard-facing interfaces:

  • Guard scheduling with shift management
  • Real-time incident logging with location tagging
  • Client-facing reporting dashboard
  • Automated timesheet generation for payroll
  • Document and certification management
  • Mobile-responsive for on-site guard access

The Resolution

Delivered a full security operations platform deployed on AWS — accessible by supervisors, guards, and clients:

  • Supervisors manage guards, shifts and incidents live
  • Guards log incidents directly from mobile devices
  • Clients receive automated weekly performance reports
  • Billing tied directly to validated timesheet data
  • All SIA licences and certifications tracked centrally
  • Zero paperwork — fully digital operations
